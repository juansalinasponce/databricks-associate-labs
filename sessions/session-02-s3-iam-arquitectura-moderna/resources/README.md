# Recursos — Sesión 02

## Actividades

### M1-E06 — Crear y organizar un bucket S3 con AWS CLI

Práctica guiada para crear un bucket con nombre globalmente único, cargar datos
sintéticos mediante `aws s3 cp` y `aws s3 sync`, verificar los objetos, completar
el flujo de una aseguradora y asignar permisos mínimos por perfil.

- [Versión del participante](actividad-m1-e06-arquitectura-s3-iam/participante.md)
- [Guía del instructor](actividad-m1-e06-arquitectura-s3-iam/instructor.md)
- [Dataset comprimido para CloudShell](actividad-m1-e06-arquitectura-s3-iam/datos-s3.zip)
- [Salida simulada para el fallback](actividad-m1-e06-arquitectura-s3-iam/salida-esperada-cli.txt)

La práctica principal requiere un sandbox AWS autorizado. Incluye un fallback
completo para participantes sin permisos de creación o acceso a S3.
