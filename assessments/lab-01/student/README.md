# Evaluación 1 — Guía del participante

## Metadata

- Sesión: 06; cobertura: sesiones 01 a 05.
- Fecha: 05 de octubre de 2026.
- Tipo: `ASSESSMENT`; nivel: fundamental.
- Duración: 120 minutos, incluidos instrucciones y break.
- Teoría: 45 minutos, 40 puntos.
- Práctica: 60 minutos, 60 puntos.
- Peso del conjunto: 30% de la nota del programa.
- Entorno: `PRACTICO_FREE`; acceso directo a S3: `PRACTICO_CONDICIONAL`.
- Datos: aseguradora ficticia; archivo sintético de pólizas.

## Orden

1. Escucha las instrucciones durante 5 minutos.
2. Resuelve [la teoría](evaluacion-teorica.md) durante 45 minutos.
3. Realiza un break de 10 minutos.
4. Resuelve [el único ejercicio práctico](ejercicio-practico.md) y entrega tu
   evidencia dentro de sus 60 minutos.

El docente informará antes del inicio si permite apuntes y asistencia de IA.
El trabajo y las explicaciones deben ser individuales.

## Archivos

- `data/polizas_evaluacion_01.csv`: fuente del ejercicio.
- `plantilla_evaluacion.py`: notebook importable en Databricks, con espacios
  para SQL o PySpark.
- `entrega.md`: plantilla para identificar tus evidencias y decisiones.

El instructor te asignará un identificador como `p07`, un catálogo y un schema
con permisos. Usa solo los nombres de salida asignados a tu identificador.

## Entrega

Entrega las respuestas teóricas por el medio indicado y, para la práctica, el
notebook o consultas exportadas junto con `entrega.md` y las capturas solicitadas.
No es necesario crear un branch, un commit o un Pull Request.

Si una restricción del entorno te bloquea, avisa al instructor y conserva la
evidencia del error. El procedimiento alternativo tiene los mismos criterios
de evaluación; no se penalizan problemas de permisos, conectividad o cuota.
